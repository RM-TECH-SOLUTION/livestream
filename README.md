# HD LiveStream React UI

Standalone React JS repository that recreates the shared screenshot sections:

- Login screen
- Dashboard
- Events Management
- Create New Event form

The app uses a simple in-app state flow:

- Login button switches to the dashboard layout
- Left sidebar navigates between Dashboard, Events, and Create Event sections

## Run

1. Install dependencies

npm install

2. Start development server

npm run dev

3. Production build

npm run build
